# Demo scenario

Use a tiny local Python fixture repository. Start from a passing checkpoint,
give the agent an issue, force one incorrect but policy-compliant patch, and
show the resulting failed tests. Then show the failure signal, rewind memory,
approved aligned restore, alternative plan, and passing verifier result.

The demo must expose the before/after Git diff and trace. A visual animation of
rewind is optional; evidence of restoration and verification is mandatory.
