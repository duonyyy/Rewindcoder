# Ablation policy

The Phase 5 smoke ablation cells are `agent_state_rewind`,
`repository_only_rewind`, and `aligned_no_memory` under
`evals/results/raw/phase5-fixture-smoke-v5/`. One-sided restore runs are
confined to disposable fixtures and must be rejected by the independent
post-restore verifier. See `docs/evaluation.md` for scope and interpretation.
